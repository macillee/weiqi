## 2. Per-Problem Reasoning

### OP-013 (opening, L3)
- 初始：白棋占 (0,0)、(8,0)、(0,8) 三角，黑棋待下。
- 答案：(8,8)。
- 推理：开局先占角价值最高，三个角已被占，剩下 (8,8) 是最后一个空角。黑棋落子即占住。
- 文案：标题≤12、描述≤60，无成人化/打击式表达。

### OP-014 (opening, L3)
- 初始：黑棋 (3,0)、(5,0) 在底边断开，白棋 (4,2) 作背景。
- 答案：(4,0)。
- 推理：(4,0) 是两块黑棋中间的空点，落子后连成一块，避免被切断。
- 文案：提示逐步引导「中间缺哪一点」。

### OP-015 (opening, L4)
- 初始：黑棋 (0,0)；白棋在右上 (8,0)、(7,1)、(8,1) 形成墙。
- 答案：(0,8)。
- 推理：两个空角为 (0,8) 与 (8,8)；(8,8) 紧贴白墙、发展空间小，(0,8) 周围开阔，是更大场。
- 文案：引导比较两角开阔程度。

### OP-016 (opening, L4)
- 初始：黑棋 (0,0)，白棋 (8,8)。
- 答案：(4,0)。
- 推理：底边中点 (4,0) 是常见的边上的大场，从角向边拆开，既守角又发展。
- 文案：提示「从角往边上走，中间的要点」。

### MIX-009 (mixed, L3) — 一子两用
- 初始：白棋 (4,4) 被黑棋 (3,4)、(5,4)、(4,5) 三面包围，仅剩 (4,3) 一气；黑棋 (3,3)/(3,4) 与 (5,3)/(5,4) 被白棋隔开。
- 答案：(4,3)。
- 推理：落子 (4,3) 填满白棋最后一气 → 吃子；同时 (4,3) 连接左右两块黑棋。capture + connect。
- 验证：初始无 0 气组；答案点空；该手吃白后黑棋有气（非自杀）。

### MIX-010 (mixed, L4) — 又逃又吃
- 初始：黑棋 (3,3) 被白 (2,3)/(3,2)/(4,3) 围，仅剩 (3,4) 一气；白棋 (3,5) 被黑 (2,5)/(4,5)/(3,6) 围，仅剩 (3,4) 一气。
- 答案：(3,4)。
- 推理：(3,4) 是黑白双方共同的最后一气。黑棋落子既逃出包围，又让白棋 (3,5) 没气被吃。escape + capture。
- 验证：初始两组均 1 气（非 0 气）；落子后白 (3,5) 0 气被吃，黑 (3,3)+(3,4) 有气。

### MIX-011 (mixed, L5) — 一子双吃
- 初始：白棋 (4,3)、(4,5) 各被黑棋三面包围，共同仅剩 (4,4) 一气。
- 答案：(4,4)。
- 推理：落子 (4,4) 同时填满两颗白棋的最后一气 → 一子双吃。
- 验证：初始两颗白棋各 1 气（非 0 气）；答案点空；该手吃两子后黑棋有气。

### MIX-012 (mixed, L5) — 切断并吃掉
- 初始：白棋 (4,3)/(4,4)/(4,5) 竖排；黑棋 (5,3)/(5,4)/(5,5) 在右，(3,3)/(3,5) 在左。白 (4,4) 被黑 (5,4) 占去一气，仅剩 (3,4) 一气，且是上下白棋的连接点。
- 答案：(3,4)。
- 推理：落子 (3,4) 吃掉中间白棋 (4,4)，把上下白棋切成两段。cut + capture。
- 验证：初始白 (4,4) 1 气（非 0 气）；答案点空；该手吃子后黑棋有气。

### LD-014 (life_death, L3) — 做出一只眼
- 初始：黑棋围成 3×3 方框（(3,3)(3,4)(3,5)(4,3)(4,5)(5,3)(5,4)(5,5)），中心 (4,4) 空。
- 答案：(4,4)。
- 推理：方框中心是眼位，落子做出一只眼，建立活棋雏形。
- 验证：初始黑框有中心与外部气（非 0 气）；答案点空；落子后黑棋有眼。

### LD-015 (life_death, L5) — 破眼杀棋
- 初始：白棋 3×3 方框（中心 (4,4) 为其唯一眼），外围被黑棋 (2,3)…(6,5) 完整包围，白棋仅剩 (4,4) 一气。
- 答案：(4,4)。
- 推理：黑棋占掉白棋唯一的眼，白棋做不出眼即被吃。kill。
- 验证：初始白框仅 (4,4) 一气（非 0 气，合法）；答案点空；落子填满白棋最后一气 → 合法吃子（非自杀，因有提子）。

### ESC-015 (escape, L3) — 快逃出去
- 初始：黑棋 (4,4) 被白 (3,4)/(5,4)/(4,3) 三面围，仅剩 (4,5) 一气。
- 答案：(4,5)。
- 推理：向白棋没围住的下方 (4,5) 落子，走出包围，气增多。
- 验证：初始黑 (4,4) 1 气（非 0 气）；答案点空；落子后黑棋有气。

### ESC-016 (escape, L4) — 选对逃路
- 初始：黑棋 (4,4)/(4,5)；白棋 (3,4)/(3,5)/(5,4)/(4,3)/(6,5)/(5,6) 包围。黑棋两气：(4,6) 与 (5,5)；其中 (5,5) 四面被堵为自杀点。
- 答案：(4,6)。
- 推理：(4,6) 通向开阔处，安全逃脱；(5,5) 四面被堵不能下。培养「区分安全逃路与自杀点」的判断。
- 验证：初始黑组 2 气（非 0 气）；答案点 (4,6) 空；落子后黑棋有气；(5,5) 虽为黑棋一气但落子即自杀，未列为答案。
